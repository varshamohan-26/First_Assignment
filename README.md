# First_Assignment
## Excel_Assignment_1_Data_Exploration
### Description
This assignment focuses on exploring and analyzing a product dataset using Excel.
The following tasks were performed as part of the assignment:

1. Sum, Count and Average
   - Calculated the total price of all products.
   - Counted the number of products in the dataset.
   - Calculated the average product price.

2. Minimum and Maximum
   - Identified the minimum price among all products.
   - Identified the maximum price among all products.

3. IF Function
   - Created a new column called "Price Range".
   - Categorized products with a price greater than or equal to $500 as "High Price".
   - Categorized the remaining products as "Standard Price".

4. SUMIF and COUNTIF Functions
   - Calculated the total price of products in the "Electronics" category using SUMIF.
   - Counted the number of products with a price less than $100 using COUNTIF.

5. Text Functions - LEFT, RIGHT and MID
   - Created a "Day" column by extracting the first two characters from the Product ID using LEFT.
   - Created a "Country Code" column by extracting the last two characters from the Product ID using RIGHT.
   - Created a "Month" column by extracting the 4th and 6th characters from the Product ID using MID.

Tools Used

- Excel
- Excel functions: SUM, COUNT, AVERAGE, MIN, MAX, IF, SUMIF, COUNTIF, LEFT, RIGHT and MID.
